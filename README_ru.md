# Прошивка для паяльника CXG-E60WT (STM8S103K3)

![Паяльник CXG-E60WT](/images/screen1.jpeg)

Прошивка для паяльника CXG-E60WT на микроконтроллере STM8S103K3. Функции: режимы сна/пробуждения, зуммер, обнаружение ошибок, калибровка АЦП по жалу, компенсация напряжения сети (110В/220В), защита от перегрева и **пропорционально-дифференциальный (PD) регулятор с ограничением мощности** для точного регулирования температуры без перерегулирования.
С этой прошивкой и небольшими аппаратными дополнениями (датчик наклона + зуммер) этот недорогой паяльник значительно превосходит свою ценовую категорию — обеспечивая стабильность температуры и функции безопасности, сравнимые с профессиональными паяльными станциями, стоящими во много раз дороже.

> [!WARNING]
> **По умолчанию прошивка рассчитана на нагревательный элемент A1326 (220В).**
> Если в вашем паяльнике установлен нагреватель **A1316 (110В)**, вы **ОБЯЗАНЫ** войти в меню настройки и установить **`HT = 1`** перед первым использованием. Использование прошивки с неверной настройкой типа нагревателя при питании от сети 220В подаст примерно **4× номинальной мощности** на нагревательный элемент и **уничтожит его за несколько секунд**.
>
> Для входа в меню настройки: удерживайте кнопку **`+`** при включении питания. Перейдите к пункту **`HT`** (последний пункт). Установите **`0`** для A1326 (220В) или **`1`** для A1316 (110В). Значение сохраняется в EEPROM автоматически.


## Выбор нагревательного элемента (A1316 vs A1326)

Многие модели CXG-E60WT поставляются с завода с нагревателем **A1316 (110В, ~55 Ом в холодном состоянии)** — предназначенным для североамериканских и японских сетей 100–120В. Эта прошивка поддерживает оба элемента через параметр `HT` в меню, однако **для европейских сетей 220–240В правильным и рекомендуемым выбором является A1326 (220В)**.

### Почему A1326 лучше для сети 230В / европейского стандарта

При питании от 240В выпрямленная шина постоянного тока составляет ~339В. Прошивка ограничивает максимальную мощность нагревателя, ограничивая скважность ШИМ (`minPwm`). Эффективный диапазон скважности определяет, сколько пространства имеет PD-регулятор для ускорения нагрева и торможения перед перерегулированием:

| | A1326 (220В, `HT=0`) | A1316 (110В, `HT=1`) |
|---|---|---|
| Сопротивление в холодном состоянии | ~200 Ом | ~55 Ом |
| Сопротивление в горячем состоянии (400 °C) | ~800 Ом | ~200 Ом |
| Макс. скважность при 240В | **47 %** | 11 % |
| Макс. мощность на горячем жале | ~60 Вт ✓ | ~63 Вт ✓ |
| Диапазон управления PD | **±47 %** | ±11 % |
| Разрешение ШИМ в уст. режиме | **0,28 Вт/шаг** | 0,13 Вт/шаг |
| Риск неверной настройки | Низкий | **Очень высокий** (нагреватель мгновенно сгорит при `HT=0`) |
| Настройка по умолчанию | ✅ Да | Нет — требует `HT=1` перед первым использованием |

Оба элемента подают ~60 Вт на жало при рабочей температуре. Разница заключается в **управляемости**: при использовании A1316 PD-регулятор располагает лишь 11% скважности. Если температура жала растёт быстрее интервала дискретизации 200 мс, регулятор реагирует с опозданием и имеет мало возможностей для коррекции. С A1326 диапазон 47% даёт регулятору достаточный запас как для ускорения нагрева, так и для чёткого торможения перед превышением уставки.

### Почему производители поставляют A1316 по всему миру

A1316 — это намеренное решение по оптимизации затрат: один SKU нагревателя покрывает каждый рынок. На сетях 110В (США, Япония) он работает отлично — прошивка работает при ~48% скважности и PD-регулятор имеет достаточный запас. На 220–240В паяльник всё равно нагревается и паяет, поэтому большинство покупателей не замечают ничего плохого. Единый глобальный склад просто дешевле, чем хранение двух вариантов.

Штатная заводская прошивка усугубляет ситуацию: она почти наверняка не реализует правильную компенсацию напряжения. На 220В с A1316 и без компенсации нагреватель работает при постоянно высокой скважности → постоянная перегрузка → ускоренная деградация керамического элемента.

Эта кастомная прошивка исправляет это: она правильно ограничивает мощность для обоих типов нагревателей при любом напряжении сети. Но физику не изменить — A1316 на 230В всегда будет оставлять PD-регулятору лишь 11% диапазона скважности.

### Поведение при питании от сети 110В (США/Япония)

Для полноты картины: вот как ведёт себя каждый нагреватель при подключении того же паяльника к сети 110В ($V_{DC} \approx 155\text{В}$):

| | A1326 (220В, `HT=0`) | A1316 (110В, `HT=1`) |
|---|---|---|
| Макс. скважность при 110В | 100 % | 48 % |
| Макс. мощность на горячем жале | ~30 Вт ❌ | ~57 Вт ✅ |
| Вывод | Недостаточная мощность — медленный нагрев, теряет температуру под нагрузкой | Работает правильно |

Таким образом, два нагревателя взаимодополняют друг друга: A1326 оптимален для 230В, A1316 для 110В. При перемещении между регионами замена нагревательного элемента (одинаковый физический формат, широко доступен) и переключение `HT` в меню обеспечивают полную производительность везде.

**Рекомендация:** если ваш паяльник поставлялся с A1316, замените его на A1326 (широко доступен, тот же физический формат). Оставьте `HT=0` (значение по умолчанию) и наслаждайтесь лучшей стабильностью температуры и более безопасной конфигурацией.

Если вы не можете найти A1326 и вынуждены использовать A1316 на 230В, установите `HT=1` в меню настройки — прошивка правильно ограничит мощность. Но сначала внимательно прочитайте предупреждение выше.

## Сборка прошивки

Вам понадобятся два инструмента:

- **stm8flash** — утилита прошивки через ST-Link: [vdudouyt/stm8flash](https://github.com/vdudouyt/stm8flash)
- **SDCC** — Small Device C Compiler: [sdcc.sourceforge.net](https://sdcc.sourceforge.net/)

## На macOS (Apple Silicon / M1):

### Установка SDCC
```
brew install sdcc
```

### Установка stm8flash
```
git clone https://github.com/vdudouyt/stm8flash.git
cd stm8flash
make
cp stm8flash /opt/homebrew/bin/
```

### Сборка прошивки
```
git clone https://github.com/Lymes/cxg-e60wt.git
cd cxg-e60wt
make
make flash
```

## На Linux:

## Отладочная сборка (UART printf на PD5)

Отладочная сборка активирует вывод трассировки через последовательный порт на **PD5 (UART1 TX, 115200 8N1, 5В)** без какого-либо влияния на релиз-прошивку — весь отладочный код удаляется препроцессором, если `DEBUG` не определён.

```bash

```

### Вывод по последовательному порту

Мониторинг с помощью `minicom -o -D /dev/cu.usbserial-* -b 115200` (или любого последовательного терминала на 115200 8N1).

| Строка | Когда | Поля |
|---|---|---|
| `B hp=… c=… al=… ah=… sl=… ds=…` | Загрузка | heatPoint, калибровка, adcMin, adcMax, таймауты sleep1/2 |
| `T=… S=… e=… a=… v=… p=…` | Каждые 200 мс | темп°C, уставка, ошибка, ADC_sensor_raw, ADC_vin_raw, скважность ШИМ (100=выкл, minPwm=полн. мощность) |
| `Sp<n>` | Нажатие кнопки | новая уставка |
| `E!<n> a=…` | Ошибка датчика подтверждена | нагреватель ВЫКЛ, показан сырой ADC |
| `OV<temp>` | Перегрев | жёсткая ошибка зафиксирована |
| `Rw T=…` | Тепловой разгон | транзистор Q1 застрял |

## Сервисное меню
Войти в сервисное меню можно, удерживая кнопку "+" при включении питания.

Двойной клик по любой кнопке циклически изменяет следующие пункты меню:
* **SOU**: включить/выключить звук, значения 0..1 (по умолчанию 1)
* **CAL**: смещение калибровки в градусах, диапазон -99..99 (по умолчанию 0)
* **SL1**: таймаут сна в минутах, диапазон 1..30 (по умолчанию 3) — поддерживает 100°C
* **SL2**: таймаут глубокого сна в минутах, диапазон 1..60 (по умолчанию 10) — нагреватель ВЫКЛ
* **FRC**: приращение температуры в принудительном режиме в градусах, диапазон 0..100 (по умолчанию 0)
* **ADL**: калибровка АЦП холодной точки (датчик при комнатной температуре) — для каждого жала
* **ADH**: калибровка АЦП горячей точки (датчик при максимальной температуре) — для каждого жала
* **HT**: тип нагревателя — `0` = A1326 (220В, по умолчанию), `1` = A1316 (110В). **Должен быть установлен правильно перед первым использованием** — см. [Выбор нагревательного элемента](#выбор-нагревательного-элемента-a1316-vs-a1326).

Для выхода из сервисного меню просто выключите/включите паяльник.

**ПРИМЕЧАНИЯ:**
* В режиме SL1 паяльник поддерживает температуру 100°C
* В режиме SL2 нагреватель полностью ВЫКЛЮЧЕН и дисплей гаснет
* Для сброса всех значений к DEFAULT нажмите кнопку "-" при включении питания
* Одновременное нажатие "+" и "-" переключает режим FORCED (дисплей показывает символ °F)

## Коды ошибок

Прошивка отображает следующие коды ошибок на 7-сегментном дисплее. Все ошибки немедленно отключают нагреватель.

| Код | Дисплей | Причина | Устранение |
|---|---|---|---|
| **ER1** | `Er1` | **Короткое замыкание датчика** — показание АЦП значительно ниже откалиброванной холодной точки (`adcVal < adcMinRT / 2`). Обычно вызвано повреждённой термопарой/NTC, мостом пайки в цепи датчика или жалом с очень плохим тепловым контактом. С подавлением дребезга: требует 500 последовательных плохих показаний (~500 мс) для срабатывания. | Переустановить или заменить жало; проверить проводку датчика. Перезапустить питание для возобновления работы. |
| **ER2** | `Er2` | **Обрыв цепи датчика / сломанный датчик** — показание АЦП превышает аппаратный порог обрыва цепи (`adcVal > 1000`). Обычно обрыв провода термопары, отсутствие жала или отказ элемента датчика. Такое же подавление дребезга 500 показаний, как у ER1. | Переустановить или заменить жало; проверить проводку датчика. Перезапустить питание для возобновления работы. |
| **OVH** | `OuH` | **Ошибка перегрева (зафиксирована)** — срабатывает при любом из двух независимых условий: **(1) Жёсткий предел** — измеренная температура превысила 480 °C; **(2) Тепловой разгон** — нагреватель был выключен, но температура продолжала расти в течение 8 последовательных секунд, что указывает на застрявший в открытом состоянии транзистор Q1 (IRF840). Ошибка остаётся зафиксированной до перезапуска питания. | Дать паяльнику остыть. Выяснить первопричину (застрявший Q1, неисправный датчик, неправильная калибровка АЦП). Перезапустить питание для сброса. |

## Калибровка АЦП по жалу (ADL / ADH)

Разные жала имеют разный тепловой контакт с керамическим нагревателем, что приводит к смещению кривой отклика АЦП. Используйте **ADL** и **ADH** для калибровки каждого жала:

1. Войдите в сервисное меню (нажмите "+" при включении)
2. Перейдите к **ADL** — при комнатной температуре паяльника отрегулируйте, пока отображаемая температура не совпадёт с окружающей (~25°C)
3. Перейдите к **ADH** — нагрейте паяльник до максимальной температуры, отрегулируйте, пока дисплей не совпадёт с известным эталоном (например, измеренным внешним термометром при ~450°C)
4. При необходимости дополнительно скорректируйте с помощью **CAL** для небольшой поправки смещения

## Управление температурой (PD + ограничение мощности)

Прошивка использует **пропорционально-дифференциальный регулятор** с **ограничением мощности** вместо простого двухпозиционного регулятора или линейной рампы:

- **Пропорциональная составляющая**: пропорционально уменьшает мощность нагревателя по мере приближения температуры к уставке
- **Дифференциальная составляющая**: определяет скорость нарастания температуры и заблаговременно тормозит — автоматически адаптируется к тепловой инерции жал разных размеров
- **Ограничение мощности**: ограничивает максимальную мощность нагревателя до `(diff + 15)%` от доступного диапазона. При 50°C до уставки → максимум 65%; при 10°C → максимум 25%; предотвращает накопление энергии в нагревательном элементе, вызывающее перерегулирование
- **Жёсткое отключение**: нагреватель немедленно выключается, когда температура достигает или превышает уставку

**Измеренные результаты (с установленным жалом):**

| Уставка | Перерегулирование | Точность в уст. режиме |
|---|---|---|
| 120°C | +2°C | ±3°C |
| 250°C | 0°C | ±4°C |

Полоса ±3-4°C в установившемся режиме — предел разрешения 10-битного АЦП с NTC датчиком.

## Защита от перегрева

Прошивка включает два независимых аппаратных уровня защиты:
* **Жёсткий предел (480°C)**: если измеренная температура превышает 480°C, нагреватель немедленно отключается, дисплей показывает **OVH**, и ошибка фиксируется до перезапуска питания
* **Тепловой разгон**: если нагреватель выключен, но температура **растёт** более чем на 60°C выше целевой в течение 8 последовательных секунд (что указывает на застрявший транзистор Q1/IRF840), срабатывает та же ошибка OVH. Естественное охлаждение (температура стабильна или падает) никогда не вызывает этой проверки.

## Компенсация напряжения сети (110В / 220В)

Делитель напряжения R14/R16 подаёт напряжение шины постоянного тока на АЦП CH1. Прошивка автоматически масштабирует максимальную мощность нагревателя для поддержания постоянной тепловой мощности независимо от напряжения сети (110В или 220В переменного тока) без ручной настройки.
